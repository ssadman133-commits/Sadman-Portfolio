05 / PROJECT EXPERIENCE

Engineering Case Studies

An honest breakdown of problem framing, execution methodology, key learning curves, and functional results.

Personal Software Project

PulsePlay

Problem

Most modern mobile media players are cluttered with intrusive ads, complex feeds, and bloated navigation when the user only wants to listen to music or watch video files smoothly.

Approach

Designed an intuitive dark user interface centered around auto-detecting local tracks, clean category tabs, VLC-inspired swipe gestures for playback control, and lightweight video organization.

What I Learned

Gained hands-on experience handling local media scanning, UI state updates, touch gesture interaction, responsive layout constraints, and crafting dark-mode interfaces that feel effortless to browse.

Result

A cohesive personal multimedia application featuring instant song search, favorite filtering, video resolution badges, and smooth distraction-free media playback.
